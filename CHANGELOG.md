# Changelog

Todas as alterações relevantes deste projeto são documentadas neste ficheiro.

## [1.0.0] - 2026-09-23

### Adicionado

- navegação no modelo Single Page Application;
- sistema de templates dinâmicos com JavaScript;
- validação visual de formulários;
- persistência de preferências com localStorage;
- organização do JavaScript em módulos ES6;
- Design System com variáveis CSS;
- Grid de 12 colunas e responsividade;
- componentes baseados em Flexbox;
- menu responsivo com dropdown e navegação móvel;
- componentes de feedback, incluindo modal, toast, alertas e badges;
- modo escuro e perfil de alto contraste;
- recursos de acessibilidade com HTML semântico e WAI-ARIA;
- integração da biblioteca AOS;
- build de produção utilizando Vite;
- configuração de publicação para Netlify.

### Qualidade

- build de produção validada com Vite;
- 0 vulnerabilidades nas dependências de produção em `npm audit --omit=dev`;
- redução aproximada de 21,70% entre os ficheiros processados sem minificação e minificados.
